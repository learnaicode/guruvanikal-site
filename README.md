# guruvanikal-site

The doorway page of [guruvanikal.com](https://guruvanikal.com). It is published once and never changes.

Each time it opens it reads `version.txt` from the `live` branch of
[learnaicode/guruvanikal](https://github.com/learnaicode/guruvanikal) and loads the site built in the
commit named there, through jsDelivr. To change what guruvanikal.com shows, run `npm run release` in
that repository. Nothing here needs to be touched.
